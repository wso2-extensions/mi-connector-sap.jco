# SAP JCo Connector for WSO2 MI

SAP JCo connector for Micro Integrator

### Compatibility

| Connector Version | Supported WSO2 MI Version |
|-------------------|---------------------------|
| 0.1.0             | MI 4.6.0        |


## Documentation

Please refer to the [SAP JCo Connector Overview](https://mi.docs.wso2.com/en/latest/reference/connectors/) documentation.

### Building From the Source

Follow the steps given below to build the connector from the source code:

1. Get a clone or download the source from [Github](https://github.com/wso2-extensions/mi-connector-sap.jco/).
2. Run the following Maven command from the `mi-connector-sap.jco` directory: `mvn clean install`.
3. The ZIP with the SAP JCo connector is created in the `mi-connector-sap.jco/target` directory.
